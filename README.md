# Formulaire de Singe 🐒

Application web de création et de gestion de formulaires, utilisable depuis une interface web et, à terme, depuis ChatGPT.

## Stack envisagée

- **Frontend :** React, TypeScript, Vite, Tailwind CSS et shadcn/ui
- **Hébergement :** Netlify (site et fonctions serveur)
- **Base de données :** Neon PostgreSQL, Drizzle ORM
- **Fichiers audio :** Cloudflare R2
- **Intégrations :** API REST et serveur MCP

## Principes

- Architecture modulaire, simple à maintenir
- Offres gratuites privilégiées ; pas d'API d'IA payante
- Secrets conservés côté serveur
- Code typé et testé

## État du projet

🚧 Projet en préparation. Le code de l'application et les instructions de lancement seront ajoutés au fil du développement.
